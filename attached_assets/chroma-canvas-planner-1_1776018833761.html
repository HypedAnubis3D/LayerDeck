Open Chroma Canvas & Upload Your Image
Click Open Chroma Canvas ↗ above. Upload the same image you analyzed here. Skip any preset color scheme — you'll build a custom palette in step 3.

Set These Values in the Settings Tab
Match these settings before generating. The layer height is what the AI optimized the color stack for.
3
Build Your Custom Palette — Slot by Slot
In Chroma Canvas, select Custom Palette. Add each slot below in order. Click any hex code to copy it, then paste it into the Chroma Canvas color picker. Slot 1 = darkest/bottom, last slot = lightest/top.
4
Find These Bambu Filaments (Optional but Recommended)
Search these names in Chroma Canvas's filament library to match actual Bambu Lab spools. Click any name to copy it.
5
Generate, Tweak & Export
Hit Generate in Chroma Canvas. If contrast looks flat, drag the gradient curve sliders. Export the .3MF and open in Bambu Studio → send to your A1 or P1.
